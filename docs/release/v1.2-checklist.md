# m4shlab v1.2 — maintainer acceptance checklist

Run this by hand before creating the release tag. Record the device, OS and
browser version with every finding. A failed row stops the release until the
cause is understood.

## Automated baseline (already run on the release tree)

| Suite | Result |
| --- | --- |
| `npm test` | 83/83 PASS |
| `npm run test:webcodecs` | 100/100 PASS |
| `npm run test:cursor` | 10/10 PASS |
| `npm run test:pwa` | 6/6 PASS, 33 precached assets |

`node --check` on every JavaScript file and `git diff --check` also pass.
These are the existing suite commands; this checklist adds no new test
command and no CI job.
